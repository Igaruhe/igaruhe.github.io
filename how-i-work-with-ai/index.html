How I work with AI

I use Claude as a fast, careful builder. I stay responsible for the goal, the decisions and the quality. These six habits make that work.

  1. Write the rules down, where the AI reads them

    Each project has rule files (CLAUDE.md) that every AI session reads first: what the project is, where it's published, what must never change, what must stay private. A rule I'd otherwise repeat in every chat lives there once.

    Example: “Card IDs come from position in the data. Add new cards at the end; never reorder.” Breaking this would lose saved progress, so it's a rule, not a memory.

  2. Turn repeated work into skills and agents

    When I do something twice, it becomes a skill (a written procedure the AI follows) or an agent (a specialist with its own instructions). Examples: a skill for adding a new app to a repository without touching the others, and a design agent that starts every redesign from public design-system foundations.

  3. Research, propose, then I decide

    For anything that changes the product, the AI first researches the guidance, then proposes options with a recommendation and trade-offs. Nothing is built until I choose. I review screenshots and the running result, not just the code.

  4. Let approved decisions teach the agent

    After I approve a decision, the lesson goes back into the agent's instructions, with the project as a worked example. The next project starts one step further. Example: “Views that share filters are views of the same content; don't give them separate tabs.”

  5. Check automatically before anything ships

    Scripts check what people forget: a structure check before every commit, contrast ratios for every colour pair, phone and desktop screenshots from a headless browser. Changes go through pull requests, never straight to the main branch.

    At work I go further: hooks that block personal data, secrets and prompt injection before an automated change is merged, and checks that stop an unattended run before a bad write.

  6. Keep private things private by design

    Copyrighted or confidential material stays in private repositories. Anything public is built from content I own, and the build script refuses to run if private names leak in. I check the AI's output for this too: it's my name on the page.
